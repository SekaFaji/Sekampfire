Privacy Policy for Sekampfire

Last updated: 30 October 2026

Sekampfire is a browser-based survival game published on the SekaFaji GitHub Pages site. This page describes the data handling visible in the game code as published on the date above.

Accounts and information you enter

The game does not require an account, name, email address, or login. The published game code does not contain an in-game analytics tracker or advertising integration.

Saved data on your device

Game progress (such as ash, upgrades, and active-run checkpoints) and audio preferences are saved in your browser's local storage. That information is stored on your device in the browser profile used to play. The game does not implement an account-based save upload or cloud synchronization.

You can erase game progress with Settings → Reset Save using two confirmation steps. That removes the game's progress data, not its separately stored audio preferences. Clearing browser site data may also erase your saves and sound settings.

Website hosting and external libraries

Sekampfire is served through GitHub Pages and loads software dependencies from unpkg (React, ReactDOM, Babel) and Tailwind CSS's CDN. When your browser connects to these providers, it sends ordinary network requests. Those providers may process request data, including IP addresses and device/browser information, under their own terms and privacy policies. Such hosting and CDN processing is outside the game's local-save implementation.

Cookies and tracking

The game code does not intentionally set tracking cookies or transmit saved game progress to an analytics endpoint. Third-party services and the browser may use their own storage or logs. This policy does not control the practices of GitHub, unpkg, Tailwind, or your browser.

How to reach the project

Questions about the game or this policy can be raised through the Sekampfire GitHub repository's issues page.

This policy describes the current public implementation and should be reviewed if the game later adds accounts, cloud saves, analytics, or other online features.
